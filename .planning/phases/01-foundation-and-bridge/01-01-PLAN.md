<task type="auto">

  <files>frontend/angular.json</files>
  <action>
  Locate the budget configuration in angular.json under projects.platform.architect.build.configurations.production.budgets.

  Increase the maximumWarning and maximumError values for "initial" bundle type:
  - Find the budget entry with "type": "initial"
  - Increase maximumWarning by 1.5MB (e.g., from "500kb" to "2mb")
  - Increase maximumError by 1.5MB (e.g., from "1mb" to "2.5mb")

  This accounts for Phaser's ~1.2MB contribution plus buffer for future assets.
  </action>
  <verify>
  - Run `cd frontend && npx ng build` and confirm no budget warnings appear

  - Verify dist/ directory is created
