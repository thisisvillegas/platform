### Day/Night Transitions

Since the recommended packs don't explicitly include day/night variants:

**Option A: Use Same Track with Volume Adjustments**
- Play same track throughout day/night
- Reduce volume slightly at night
- Add subtle ambient effects (crickets, etc.) using SFX

**Option B: Create Crossfade Transitions**
- Have two similar-mood tracks (beatscribe pack has 16 tracks)
- Crossfade between them on time change
- Maintains continuity while providing variety

**Option C: Add Supplementary Ambient Layer**
- Layer ambient SFX (wind, crickets) on top of day music
- Switch to different ambient layer (owls, stars) at night
- Same music track, different feel

## Integration Plan

### Phaser 3 Audio Setup

1. **Load Audio Assets:**
   ```typescript
   // Load music
   this.load.audio('town-music', 'assets/audio/music/town-theme.ogg');
   this.load.audio('tavern-music', 'assets/audio/music/tavern-theme.ogg');

   // Load SFX
   this.load.audio('door-open', 'assets/audio/sfx/door-open.ogg');
   this.load.audio('footstep', 'assets/audio/sfx/footstep.ogg');
   this.load.audio('pickup', 'assets/audio/sfx/pickup.ogg');
   ```

2. **Play Music (Looping):**
   ```typescript
   const music = this.sound.add('town-music', { loop: true, volume: 0.5 });
   music.play();
   ```

3. **Play SFX (One-shot):**
   ```typescript
   this.sound.play('door-open', { volume: 0.7 });
   ```

4. **Implement Time of Day Changes:**
   ```typescript
   updateTimeOfDay(hour: number) {
     if (hour < 6 || hour >= 18) {
       // Night time - reduce music volume
       currentMusic.setVolume(0.3);
       // Add night ambient SFX loop if needed
     } else {
       // Day time - normal volume
       currentMusic.setVolume(0.5);
     }
   }
   ```
