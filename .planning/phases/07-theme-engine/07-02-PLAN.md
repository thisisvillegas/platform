  Extend ThemeEngine.ts to handle particles:

  Add private property: particleEmitter: Phaser.GameObjects.Particles.ParticleEmitter | null

  In applyTheme():
  - If existing particleEmitter, destroy it before applying new theme
  - If theme.particles exists:
    - Create graphics object for particle texture (colored square based on theme.particles.color)
    - Generate texture from graphics: scene.add.graphics().fillStyle(color).fillRect(0, 0, 4, 4).generateTexture('particle-{themeId}')
    - Create particle emitter:
      - frequency: calculate from density (e.g., 1000 / density ms)
      - speed: { min: theme.particles.speed * 0.8, max: theme.particles.speed * 1.2 }
      - gravityY: 50 for falling effect
      - lifespan: 5000
      - scale: { start: 1, end: 0.5 }
      - alpha: { start: 1, end: 0 }
      - emitZone: top edge of camera view (full width)
    - Start emitter

  Include particle type-specific tweaks:
  - "hearts": rotate particles, slower fall
  - "snowflakes": faster fall, more density
  - "leaves": rotate + drift horizontally
  - "fog": very slow fall, larger scale
  </action>
