  <name>Task 1: Create MongoDB VisitorProgress model and backend API routes</name>
  <files>backend/src/models/VisitorProgress.ts, backend/src/routes/worldRoutes.ts</files>
  <action>
    Create VisitorProgress.ts Mongoose model:
    - Schema fields:
      - passCode (String, indexed, required) - identifies the visitor
      - collectibles (Array of Strings) - collected collectible IDs
      - achievements (Array of Strings) - unlocked achievement IDs
      - buildingsVisited (Array of Strings) - building IDs entered
      - npcsInteracted (Array of Strings) - NPC IDs talked to
      - dialogueCount (Number) - total conversations
      - timeSpent (Number) - cumulative seconds in world
      - lastPosition (Object {x: Number, y: Number}) - last world coordinates
      - firstVisit (Date) - timestamp of first visit
      - lastVisit (Date) - timestamp of last update
    - Indexes: passCode (unique)

    Add to worldRoutes.ts:
    - POST /api/world/progress - Save or update visitor progress
      - Requires guest JWT (use guestAuth middleware from Phase 5)
      - Extract passCode from JWT
      - Upsert visitorProgress document (update if exists, insert if new)
      - Body: { collectibles, achievements, buildingsVisited, npcsInteracted, dialogueCount, timeSpent, lastPosition }
      - Return: { success: true, progress }
    - GET /api/world/progress - Load visitor progress
      - Requires guest JWT
      - Extract passCode from JWT
      - Find visitorProgress by passCode
      - Return: { success: true, progress } or empty progress if not found
  </action>
  <verify>POST/GET /api/world/progress work with valid guest JWT, save and retrieve progress data</verify>
  <done>VisitorProgress model and API routes handle progress persistence via guest JWT</done>
</task>

<task type="auto">
  <name>Task 2: Create frontend ProgressService to sync with backend</name>
  <files>frontend/src/app/game/services/ProgressService.ts</files>
  <action>
    Create ProgressService.ts Angular service:
    - Injectable service that wraps progress API calls
    - Methods:
      - loadProgress() - GET /api/world/progress, returns Observable<ProgressData>
      - saveProgress(data) - POST /api/world/progress with data, returns Observable<Response>
      - autoSave(interval) - set up periodic auto-save (every 30 seconds or on visibility change)
    - Include guest JWT token from localStorage in Authorization header
    - Handle errors gracefully (network failures, expired tokens)
    - Expose current progress state as BehaviorSubject for reactivity
    - Debounce save calls to avoid excessive API hits (use RxJS debounceTime)
  </action>
  <verify>ProgressService can call loadProgress and saveProgress with guest JWT, handles errors</verify>
  <done>ProgressService provides clean API for loading and saving visitor progress</done>
